# Student Result Calculator

A simple C++ program for the Software Construction and Development Lab.

The program reads a student's name, roll number, and marks in three subjects, then prints the total, percentage, and letter grade.

## Compile and run

```bash
g++ -o student_result student_result.cpp
.\student_result.exe
```

## Grade scale

| Percentage | Grade |
|------------|-------|
| 90 - 100   | A     |
| 80 - 89    | B     |
| 70 - 79    | C     |
| 60 - 69    | D     |
| Below 60   | F     |
